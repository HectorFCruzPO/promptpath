# Contributing

Use the Contributions page to suggest a new prompt or an edit. Explain the task, provide the full proposed wording, and give a reason for the change. Good prompts define an outcome, required inputs, output structure, boundaries, and verifiable completion checks.

For an edit, choose the existing prompt so the proposal can be compared with the curated version. Test with a normal case, missing information, and conflicting evidence. Include only synthetic or de-identified examples.

Proposals start pending. They are not automatically applied. Reviewer permissions and an approval interface are planned; for now a maintainer must inspect a proposal and deliberately update the curated source through the version-controlled development workflow.
